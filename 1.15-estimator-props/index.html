推定量の性質：不偏性・一致性・有効性の理論

推定量の良さを測る物差し（不偏性・平均二乗誤差・一致性・有効性）と、分散の下限を与えるクラーメル・ラオの不等式、最小二乗法の良さを保証するガウス・マルコフの定理を、図で学びます。

このモジュールでできるようになること

推定法では、同じ一様分布のデータから、最尤推定とモーメント法で違う答えが出ました。どちらの推定量が良いのかを決めるには、物差しが要ります。

  • 分散を n で割る推定量と n−1 で割る推定量を、偏りとばらつきの両方で比べられる
  • 母平均を標本平均と標本中央値のどちらで推定すべきかを、分散の比で言える
  • 不偏推定量の分散がどこまで小さくできるか（クラーメル・ラオの下限）を、正規分布で計算できる

1. 良い推定量とは

ダーツで見る偏りとばらつき

1回の推定値が真の値に近かったかどうかでは、推定量の良し悪しは決まりません。データをとり直すたびに推定値は変わるからです。そこで、とり直しを何度も繰り返したときの推定値の散らばり方で比べます。的の中心を真の値 θ、矢1本を「1回分のデータから計算した推定値 θ^」と見ます。

この図の見方を、次の節から1つずつ式にします。

  • 不偏性：推定値の平均が真の値（E[θ^]=θ）。図の上の段

  • 有効性：不偏な推定量の中でばらつきが小さい（Var(θ^) が最小）。図の左上

2. 不偏性と平均二乗誤差

不偏分散と n で割る分散

正規分布の分散 σ2 をデータから推定するとき、平均からのずれの二乗和を n で割るか n−1 で割るかで、2つの推定量ができます。

S2=n−11​i=1∑n​(Xi​−Xˉ)2

σ^2=n1​i=1∑n​(Xi​−Xˉ)2

S2 は E[S2]=σ2 で不偏なので不偏分散と呼びます。σ^2（最尤推定量）は平均が nn−1​σ2 で、少し小さめに偏ります。

なぜ n−1 で割ると偏りが消えるのか

Xˉ はデータ自身の真ん中なので、データから Xˉ までのずれは、真の μ までのずれより平均して小さくなります。どれだけ小さいかは、ずれの二乗和を2つに分けると分かります。

∑(Xi​−μ)2=∑(Xi​−Xˉ)2+n(Xˉ−μ)2

  • 左辺の平均は nσ2（1個あたり σ2 が n 個）
  • 右辺の第2項の平均は n×σ2/n=σ2（Xˉ の分散が σ2/n のため）
  • だから第1項の平均は (n−1)σ2 で、n−1 で割るとちょうど σ2 になる

n で割ると σ2 の nn−1​ 倍しか出ません（n=5 なら0.80倍）。推定法の表で見た偏りは、ここから来ています。

偏りが無い方が、真の値に近いとは限らない

図では、S2 は平均が真の値にありますが幅が広く、σ^2 は平均が少し左にずれていますが幅が狭くなっていました。どちらが真の値に近いかは、ずれの2乗の平均で測ります。これが平均二乗誤差（MSE）で、偏りの2乗と分散の和に分かれます。

MSE(θ^)​=E[(θ^−θ)2]={E[θ^]−θ}2+Var(θ^)​

第1項はダーツの図の「平均が中心からどれだけずれているか」、第2項は「矢がどれだけ散らばっているか」です。図の2つ（n=5、σ2=1）を数で比べます。

分散の数は、4S2/σ2 が自由度4のカイ二乗分布に従い、その分散が 2×4=8 であることから出ます（標本分布）。σ2=1 なら Var(S2)=8/42=0.50 で、σ^2=54​S2 の分散は 0.82×0.50=0.32 です。MSE は σ^2 が (−0.20)2+0.32=0.36 で、S2 より小さくなります。

偏りがあっても、分散が小さければ MSE は小さくなることがあります。不偏性だけで推定量の良し悪しは決まりません。

3. 一致性

n を増やすと真の値に集まる

一致性は、1つの推定量に使うデータの数 n を増やしたとき、推定値が真の値に集まる性質です。

不偏性と一致性は別の性質です。X1​ は不偏ですが一致しません。逆に σ^2 は不偏ではありませんが、偏り −σ2/n と分散がどちらも0に近づくので一致します。

4. 有効性

不偏な推定量どうしをばらつきで比べる

正規分布の平均 μ を推定するとき、標本平均も標本中央値も、平均すると μ になる不偏推定量です。どちらを使うべきでしょうか。不偏な推定量どうしなら、分散が小さい方が真の値の近くに集まります。分散の比を相対効率と呼びます。

相対効率は π/2≈1.57 で、正規分布では平均の方が効率的です（中央値の分散は十分統計量・順序統計量で求めました）。裾の重い分布では、中央値の方が有利になることもあります。

不偏推定量の中で分散が最小のものを最小分散不偏推定量（MVUE）と呼びます。十分統計量を使うと不偏推定量を改良できること（ラオ・ブラックウェルの定理）が、MVUE を探す手がかりになります。

5. 分散の下限：クラーメル・ラオの不等式

平均よりばらつきの小さい不偏推定量はあるか

中央値は平均に負けました。では、もっと工夫すれば、平均より分散の小さい不偏推定量が見つかるでしょうか。答えは「見つからない」です。n 個の独立なデータからの不偏推定量の分散には、どう工夫しても下回れない下限があります。

Var(θ^)≥nI(θ)1​,I(θ)=E[(∂θ∂logf(X;θ)​)2]

I(θ) はフィッシャー情報量で、1個のデータが θ についてもつ情報の量です。

  • かっこの中の微分は、θ を少し動かしたときに対数尤度がどれだけ変わるか（傾き）
  • その2乗の平均が大きいほど、尤度の山が鋭く、θ を狭く絞り込める
  • データが n 個なら情報も n 倍になり、下限は 1/n に下がる

推定法の尤度の図で、100回中70回の山が10回中7回の山より鋭かったのと同じです。

正規分布の平均で確かめる

σ2 が既知の N(μ,σ2) で θ=μ とします。

∂μ∂logf​I(μ)​=σ2x−μ​=E[σ4(X−μ)2​]=σ21​​

下限は σ2/n で、Var(Xˉ)=σ2/n とちょうど等しくなります。下限に届く不偏推定量を有効推定量と呼び、Xˉ はその代表例です。上の図の中央値は、この下限より約1.57倍大きい分散です。

6. 最小二乗法の良さ：ガウス・マルコフの定理

どの範囲で「最良」か

回帰の係数は、ふつう最小二乗法（OLS）で求めます。OLS より分散の小さい推定量はあるでしょうか。答えは、どの範囲の推定量と比べるかで変わります。線形モデル y=Xβ+ε で考えます。

  • 誤差が独立・等分散・期待値0なら、OLS は線形不偏推定量の中で分散が最小です（BLUE）。誤差の正規性は要りません
  • 誤差が正規分布に従うなら、OLS は最尤推定と一致し、線形に限らずすべての不偏推定量の中で分散が最小（MVUE）になります

回帰そのものは重回帰分析とモデル評価で学びます。

確認クイズ（抜粋）

Q1. 「推定量の期待値が真の値に等しい」という性質を何と呼ぶか？

A. 不偏性

Q2. 正規分布から5個とり、分散 σ2 を不偏分散 S2（n−1 で割る）と σ^2（n で割る）で推定します。平均二乗誤差（MSE）について正しいものはどれか？

A. σ^2 の方が MSE は小さい

Q3. クラーメル・ラオの不等式においてフィッシャー情報量 I(θ) が大きいほど推定はどうなるか？

A. 分散の下限が下がり、より精密な推定ができうる
