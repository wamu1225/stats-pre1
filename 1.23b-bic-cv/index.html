BIC・マローズの Cp・クロスバリデーション

罰則を n とともに重くする BIC、線形回帰で使うマローズの Cp、データを分けて予測誤差を直接測るクロスバリデーションを、AIC と比べながら学びます。

このモジュールで学ぶこと

KL情報量と AICでは、手元のデータで最大化した対数尤度から甘さ k を差し引いた AIC で、新しいデータに強いモデルを選びました。ただ、AIC は予測のための物差しで、効いている変数だけを当てたいときには余分な変数を残しがちです。また、分布を仮定した近似に頼っています。読み終えると、次の3つができるようになります。

  1. AIC と BIC を対数尤度とパラメータ数から計算し、選ぶモデルが変わる理由を説明できる
  2. 線形回帰でマローズの Cp​ を計算して読める
  3. クロスバリデーションの手順と、AIC との関係を説明できる

1. AIC・BIC・Cp​：罰則の付け方

効いている変数を特定したいとき、AIC では n が増えても余分なパラメータを含むモデルを選ぶ確率が0になりません（余分が1個なら、尤度比統計量（−2ℓ の差）∼χ12​ が罰則の差2を超える確率なので、余分なモデルを選ぶ確率は約16%）。罰則を n とともに重くしたのがBIC（ベイズ情報量規準）です：

BIC=−2ℓ(θ^)+klogn

AICBIC
罰則2kklogn
ねらい予測の良さ真のモデルを当てる
大標本で余分なものも選ぶ真のモデルを選ぶ確率→1

BIC の「確率→1」（一致性）は、データを生んだ真のモデルが候補にあるときの性質です。n≥8 なら logn>2 なので、BIC のほうがパラメータの追加に厳しく、n が大きいほど差が広がります（n=100 なら logn≈4.6）。

📖 マローズの Cp​

線形回帰なら、AIC の −2ℓ を残差平方和に替えて、尤度を書かずに同じ補正ができます。それがマローズの Cp​ です。全変数を使ったモデルの誤差分散の推定値を s2、候補モデルの残差平方和を RSS、係数の数を AIC と同じく k（定数項を含む）、データ数を n として、

Cp​=s2RSS​−n+2k

と定義します。k を増やすと RSS は減りますが、2k が罰則として増えます。必要な変数を落としていなければ E[RSS]≈(n−k)σ2（s2≈σ2）なので Cp​ は k の近くになります。Cp​ が k を大きく超えない候補のうち、k が小さいものが良いモデルです。誤差が正規分布に従う線形回帰では、AIC と Cp​ は標本が大きいとき、ほぼ同じ順位づけになります。

つまずきやすい点：Cp​ の s2 は「全変数を入れたモデル」から求めるので、候補モデルごとに変わりません。候補モデルだけで s2 を求めると、Cp​ の意味が失われます。

2. クロスバリデーション（交差検証）

AIC は分布を仮定したうえでの近似でした。仮定に頼らず、データを訓練用と検証用に分けて、将来データでの予測誤差を直接測るのがクロスバリデーション（Cross-Validation, CV）です。

K分割交差検証（K-fold CV）：データを K 個の塊（フォールド）に等分し、1つを検証用・残り K−1 を訓練用として K 回繰り返します。全点を1回ずつ検証に使い、その平均を将来データでの予測誤差の推定値とします。

Leave-One-Out CV（LOOCV）：K=n とし、学習データを最大限に使う場合です。1つずつ除いて学習し、除いた1点で検証を繰り返します。

CV と AIC の理論的関係

LOOCV は AIC と漸近的に同値（n が大きいとほぼ一致する）であることが知られています（Stone, 1977）。検証誤差を対数尤度で測ると、AIC と同じ量（新しいデータでの対数尤度）を推定することになるからで、大標本では同じモデルを選ぶ傾向があります。違いは：

  • AIC：式で求める近似（計算が速い、対数尤度にもとづき理論的）
  • CV：検証用データで実際に測る。2乗誤差など任意の物差しで測れる、計算コストが高い（K 回学習）

3. 数値例：AIC と BIC で選ぶモデルが変わる

BIC が AIC より厳しいことが、実際に結論を変える例です。カフェの売上を予測する3つのモデルを比べます（n=100）。k は回帰係数の数で、誤差の分散の1個は3つに共通なので差には影響しません。

モデルk最大対数尤度 ℓAICBIC
M1：定数のみ1−150302304.6
M2：気温2−130264269.2
M3：M2＋休日・イベント4−126260270.4

AIC では M3（260）が選ばれ、M2 は ΔAIC=4 で同等とは言えません（Δ>2。目安はKL情報量と AIC）。BIC では M2（269.2）が最小です（M3 との差1.2）。パラメータ2個を足して −2ℓ が8下がりました。AIC は8が罰則の増え4より大きいので M3 を採り、BIC は8が罰則の増え 2log100≈9.2 に届かないので採りません。

モデル選択の実務的な原則

「AIC が最小だから最良」と機械的に決めるのは危険です。実務では：

  1. 目的で選ぶ：予測なら AIC・CV、効いている変数の特定なら BIC（上の例の予測なら M3）
  2. 解釈可能性：複雑なモデルが少しだけ AIC が低くても、シンプルなモデルを選ぶ判断もある
  3. 検証データの確保：CV や別データセットで予測精度を確認することが理想

確認クイズ（抜粋）

Q1. AIC と BIC を比較したとき、BIC の特徴として正しいものはどれか？

A. BIC の罰則は klogn でデータ数 n が多いほど大きくなる

Q2. K分割交差検証（K-fold CV）の主な目的はどれか？

A. 新しいデータでの予測誤差を推定する

Q3. Leave-One-Out CV（LOOCV）はどのような操作か？

A. データ数と同じ回数だけ「1個除いて学習・その1個でテスト」を繰り返す
