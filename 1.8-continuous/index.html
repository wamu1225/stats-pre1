連続型分布の基礎：指数・ガンマ・ベータ・コーシー・対数正規

待ち時間・割合・掛け算で増える量など、連続した値をとる量の分布を、ポアソン分布や正規分布とのつながりから学びます。

このモジュールで学ぶこと

前のモジュールまでは、回数のように 0, 1, 2, … と飛び飛びの値をとる分布（離散型の分布）を学びました。このモジュールでは、待ち時間や割合のように、連続した値をとる量の分布（連続型の分布）を5つ学びます。

  • 指数分布：次の出来事までの待ち時間（0以上）
  • ガンマ分布：α 件目の出来事までの待ち時間（0以上）
  • ベータ分布：割合や確率（0から1）
  • 対数正規分布：所得や株価のように掛け算で増える量（0より大きい）
  • コーシー分布：極端な値がよく出る量（すべての実数）

指数分布とガンマ分布は、ポアソン分布と同じ「出来事がランダムに起きる」場面から生まれます。ポアソン分布は「一定の時間に何件起きるか」を数えました。こちらは「次の出来事まで、どれだけ待つか」を測ります。

1. 指数分布：次の出来事までの待ち時間

1時間に平均3件の電話が来る窓口で、次の電話は何分後に来るでしょうか。件数がポアソン分布に従うとき、この待ち時間 X は指数分布（Exponential Distribution）に従います。

式は、ポアソン分布から次のように作れます。

  1. 待ち時間が t より長いのは、長さ t の時間に電話が1件も来ないときです
  2. 単位時間あたりの平均件数を λ とすると、長さ t の時間の件数は平均 λt のポアソン分布に従います
  3. 平均 m のポアソン分布で0件の確率は e−m なので、P(X>t)=e−λt です

1からこれを引いた F(t)=1−e−λt が累積分布関数で、それを t で微分すると確率密度関数になります。

f(t)=λe−λt,t≥0

窓口の例では、1分あたり λ=3/60=0.05 件です。20分より長く待つ確率は e−0.05×20=e−1≈0.37 です。

期待値と分散は次のとおりです。

E[X]=λ1​,Var(X)=λ21​

1分に0.05件なら、平均の待ち時間は 1/0.05=20 分です。1時間に3件なら20分に1件の割合なので、直感とも合います。

無記憶性

指数分布は、幾何分布と同じ無記憶性を持ちます。すでに s 分待ったとき、さらに t 分以上待つ確率は、最初から t 分以上待つ確率と変わりません。

P(X>s+t∣X>s)​=e−λse−λ(s+t)​=e−λt=P(X>t)​

窓口で30分待って電話が来なくても、そこからさらに20分以上待つ確率は、やはり0.37です。「長く待ったから、そろそろ来るはず」とはなりません。連続型の分布で無記憶性を持つのは、指数分布だけです。

2. ガンマ分布：α 件目までの待ち時間

同じ窓口で、3件目の電話が来るまでの時間を考えます。1件ごとの待ち時間はどれも指数分布に従い、互いに影響しません。3件目までの時間は、その3つを足したものです。

このように、指数分布に従う独立な待ち時間を α 個足した量の分布がガンマ分布 Ga(α,λ) です。

確率密度関数は次の式です。α=1 を入れると、指数分布の式に戻ります。

f(x)=Γ(α)λα​xα−1e−λx,x>0

Γ(α) はガンマ関数で、全体の面積を1にするための数です。定義は Γ(α)=∫0∞​tα−1e−tdt で、次の性質を使います。

  • Γ(α+1)=αΓ(α)、Γ(1)=1
  • 正の整数 n では Γ(n)=(n−1)!（例：Γ(3)=2!=2）
  • Γ(1/2)=π​

期待値と分散は、指数分布のちょうど α 倍です。独立な待ち時間を α 個足しているので、期待値も分散も足し算になるからです。

E[X]=λα​,Var(X)=λ2α​

窓口の例で3件目までなら、平均は 3/0.05=60 分です。

同じ理由で、λ が等しい独立なガンマ分布どうしを足すと、α を足したガンマ分布になります（再生性）。2件目までの時間に、そこから3件来るまでの時間を足せば、5件目までの時間になるということです。

​Ga(α1​,λ)+Ga(α2​,λ)=Ga(α1​+α2​,λ)​

本によっては、2つ目の母数に λ ではなく、その逆数 β=1/λ を使って Ga(α,β) と書きます。その場合、期待値は αβ、分散は αβ2 です。問題文がどちらの書き方かを確かめてください。

ガンマ分布は、後で学ぶカイ二乗分布 χ2(k) とも同じ仲間で、Ga(k/2,1/2) と同じ分布です。カイ二乗分布は、標準正規分布（平均0、分散1の正規分布）に従う独立な k 個の変数の二乗和の分布で、標本分布の相互関係で学びます。正規分布は、平均を中心に左右対称な釣鐘形の分布で、正規分布の性質で学びます。

3. ベータ分布：割合の分布

広告のクリック率や選手の打率のように、0から1の間の値をとる量があります。こうした割合がどのあたりにありそうかを表すのがベータ分布 Beta(α,β) です。

f(x)=B(α,β)xα−1(1−x)β−1​,0<x<1

分子の xα−1(1−x)β−1 は、成功確率が x のとき「成功 α−1 回、失敗 β−1 回」が起きる確率と同じ形です。α が大きいほど x の大きい側が持ち上がり、山が右へ寄ります。

B(α,β) はベータ関数で、全体の面積を1にするための数です。ガンマ関数を使うと B(α,β)=Γ(α)Γ(β)/Γ(α+β) と書けます。

期待値と分散は次のとおりです。

E[X]Var(X)​=α+βα​=(α+β)2(α+β+1)αβ​​

例えば Beta(2,5) の期待値は 2/7≈0.29 です。α=β=1 では f(x)=1 となり、0から1のどこも同じ高さの一様分布になります。

ベータ分布は、ベイズ推定で「成功確率がどのくらいの値でありそうか」を表す分布（事前分布）としてもよく使われます。

4. 対数正規分布：掛け算で増える量

所得や株価のように、0より大きく、一部がとても大きな値になる量があります。こうした量は、対数 lnX をとると正規分布に従うことがよくあります。このときの X の分布が対数正規分布 LogN(μ,σ2) です。μ と σ2 は、X ではなく lnX の平均と分散です。

対数をとると正規分布になる理由は、掛け算にあります。株価が毎日「前の日の何倍か」で動くとすると、n 日後の株価 Xn​ は、最初の株価 X0​ に毎日の倍率 r1​,r2​,… を掛けたものです。対数をとると、掛け算は足し算に変わります。

lnXn​=lnX0​+lnr1​+⋯+lnrn​

独立な量をたくさん足したものは正規分布に近づきます（中心極限定理。大数の法則と中心極限定理で学びます）。なので lnXn​ は正規分布に近く、Xn​ は対数正規分布に近くなります。

期待値と分散は次のとおりです。

E[X]Var(X)​=eμ+σ2/2=(eσ2−1)e2μ+σ2​

μ=0、σ=1 で比べます。lnX の真ん中の値は0なので、X の真ん中の値（中央値）は e0=1 です。一方、期待値は e0.5≈1.65 です。右に長い裾が平均を引っ張るので、平均は中央値より大きくなります。所得の平均が、真ん中の人の所得より高く出るのも同じ理由です。

5. コーシー分布：期待値を持たない分布

コーシー分布は、正規分布に似た左右対称の山の形をしていますが、裾がずっと重い分布です。標準的なコーシー分布の確率密度関数は次の式です。

f(x)=π(1+x2)1​,−∞<x<∞

x が大きくなっても、密度は 1/x2 くらいの速さでしか小さくなりません。正規分布の e−x2/2 よりずっと遅いので、極端な値がよく出ます。

この裾の重さのために、コーシー分布には期待値も分散もありません。期待値を計算する積分 ∫∣x∣f(x)dx が無限大になるからです。

参考積分が無限大になる理由読まなくても先へ進めます

x が大きいところでは、∣x∣f(x)=π(1+x2)∣x∣​ はほぼ π∣x∣1​ です。1/x を積分すると lnx になり、x を大きくするといくらでも大きくなるので、積分は収束しません。

期待値が無いので、大数の法則（データを増やすほど標本平均が母平均に近づく）も成り立ちません。コーシー分布に従う独立な n 個の値の平均は、n をいくら増やしても、元と同じコーシー分布に従います。1万個の平均をとっても、1個だけ見たときと散らばり方が変わりません。

そのため、コーシー分布の真ん中を推定するときは、平均ではなく中央値を使います。

コーシー分布は、自由度1の t 分布と同じ分布です。また、標準正規分布に従う独立な2つの変数の比 Z1​/Z2​ も、コーシー分布に従います。

確認クイズ（抜粋）

Q1. 指数分布の「無記憶性」の正しい説明はどれか？

A. すでにどれだけ待ったかに関わらず、残り時間の分布は最初と同じ

Q2. 指数分布とポアソン分布の関係として最も正しいものはどれか？

A. ポアソン過程のイベント間隔の分布が指数分布

Q3. ガンマ分布 Ga(α,λ) で α=1 のとき、何の分布と一致するか？

A. 指数分布 Exp(λ)
