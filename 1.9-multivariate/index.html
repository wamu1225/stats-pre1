多変量正規分布・変数変換・極値分布

相関をもつ正規分布（多変量正規分布）と条件付き分布、ヤコビアンを使う変数変換、最大値・最小値の分布（極値分布）を学びます。

このモジュールで学ぶこと

正規分布の性質では、1つの変数の正規分布を学びました。このモジュールでは、そこから広げた3つのテーマを学びます。

  • 多変量正規分布：身長と体重のように、相関をもつ複数の変数をまとめて扱う正規分布
  • 変数変換：X の分布から、Y=g(X) の分布を求める方法
  • 極値分布：n 個の値の最大値や最小値が従う分布

1. 多変量正規分布：相関をもつ正規分布

身長と体重を同時に測ると、身長が高い人ほど体重も重い傾向があります。身長も体重も1つずつ見れば正規分布に近くても、別々に見ているかぎり、この関係は表せません。複数の変数を相関も含めてまとめて表す正規分布が多変量正規分布です。

2つの変数 X,Y の場合（2変量正規分布）は、次の5つの数で決まります。

  • それぞれの平均 μX​,μY​
  • それぞれの分散 σX2​,σY2​
  • 相関係数 ρ（相関・偏相関・条件付き期待値で学びました）

平均を縦に並べたものを平均ベクトル μ、分散と共分散 ρσX​σY​ を並べたものを分散共分散行列 Σ と呼びます。

μ=(μX​μY​​),Σ=(σX2​ρσX​σY​​ρσX​σY​σY2​​)

p 個の変数の多変量正規分布を Np​(μ,Σ) と書きます。

確率密度関数は次の式です。

f(x)​=(2π)p/2∣Σ∣1/21​×exp(−21​(x−μ)⊤Σ−1(x−μ))​

exp の中の (x−μ)⊤Σ−1(x−μ) は、1変数の正規分布の (σx−μ​)2 を多変数に広げたものです。中心からの距離を、ばらつきの大きさと相関で測り直した量で、マハラノビス距離の2乗と呼びます。この値が同じ点を結ぶと楕円になり、上の図の等高線はこの楕円です。p=1 にすると、1変数の正規分布の式に戻ります。

多変量正規分布には、次の性質があります。

  • 周辺分布：1つの変数だけを取り出すと正規分布です。X は N(μX​,σX2​) に従います
  • 線形変換：AX+b も多変量正規分布 N(Aμ+b, AΣA⊤) に従います。例えば和 X+Y は、平均 μX​+μY​、分散 σX2​+σY2​+2ρσX​σY​ の正規分布です
  • 条件付き分布：X の値が分かったときの Y も正規分布です
  • 無相関と独立：ρ=0 なら X と Y は独立です

条件付き分布：X が分かったときの Y

X=x と分かったとき、Y は次の平均と分散の正規分布に従います。

E[Y∣X=x]Var(Y∣X=x)​=μY​+ρσX​σY​​(x−μX​)=σY2​(1−ρ2)​

身長（平均170cm、標準偏差6cm）と体重（平均65kg、標準偏差8kg）の相関が0.5だとします。身長176cmの人の体重は、次のように求まります。

  1. 身長は平均より6cm、つまり標準偏差1つぶん高い
  2. 体重の平均は、体重の標準偏差の ρ=0.5 倍（0.5×8=4 kg）だけ上がって69kg
  3. 分散は 64×(1−0.52)=48 で、標準偏差は約6.9kg

身長が分かると、体重の予想は65kgから69kgへ動き、ばらつきは8kgから6.9kgへ小さくなります。

条件付き期待値 E[Y∣X=x] は x の1次式で、図の黒い直線です。後で学ぶ重回帰分析とモデル評価の回帰直線と同じ式になります。条件付き分散は x によらず一定です。

無相関なら独立（多変量正規分布のとき）

ρ=0 のとき、Σ の右上と左下が0になり、exp の中が「X だけの項」と「Y だけの項」の和に分かれます。すると密度は「X の正規分布の密度」×「Y の正規分布の密度」になります。密度が積に分かれることが独立の定義なので、無相関なら独立です。

一般の分布では、無相関でも独立とは限りません。X と Y がそれぞれ正規分布に従うだけでも足りません。2つがまとめて多変量正規分布に従うことが条件です。

参考それぞれは正規分布なのに、無相関で独立でない例読まなくても先へ進めます

X が N(0,1) に従い、S は X と独立に +1 か −1 を確率1/2ずつとるとします。Y=SX とおくと、Y も N(0,1) に従い、Cov(X,Y)=E[S]E[X2]=0 です。

しかし ∣Y∣=∣X∣ なので、X が分かれば Y は2通りに絞られ、独立ではありません。点 (X,Y) は2本の直線 y=x と y=−x の上にしかないので、2変量正規分布ではありません。

2. 変数変換：Y=g(X) の分布

X の分布が分かっているとき、Y=g(X) の分布を求めたい場面があります。例えば「lnX が正規分布に従うとき、X はどんな分布か」（対数正規分布）という問いです。

考え方は「確率は移しても変わらない」です。X がある区間に入る確率と、その区間を g で移した先に Y が入る確率は同じです。区間の幅が変われば、同じ面積を保つために高さ（密度）が変わります。確率分布の基礎で、X を2倍すると幅が2倍、山の高さが半分になったのと同じです。

g が単調増加か単調減少なら、x=g−1(y) として、Y の密度は次の式です。

fY​(y)=fX​(x)​dydx​​,x=g−1(y)

∣dx/dy∣ は「y を少し動かしたとき、x がどれだけ動くか」で、幅の伸び縮みを補正します。これをヤコビアンと呼びます。図の Y=X2 では x=y​、dx/dy=1/(2y​) で、fX​=1 なので fY​(y)=1/(2y​) です。

例：X が N(0,1) に従い、Y=eX のとき。x=lny、dx/dy=1/y なので、次の式になります。

fY​(y)=2π​1​e−(lny)2/2⋅y1​,y>0

これが対数正規分布 LogN(0,1) の密度です。

単調でない変換

X が N(0,1) に従い Y=X2 のときは、1つの y に x=y​ と x=−y​ の2つが対応します。両方の寄与を足します。

fY​(y)​={fX​(y​)+fX​(−y​)}2y​1​=2πy​1​e−y/2,y>0​

これは自由度1のカイ二乗分布の密度で、次の標本分布の相互関係で使います。

2つの変数をまとめて変換する

(X,Y) から (U,V) へ変換するときは、∣dx/dy∣ の代わりに、偏微分を並べた行列式 J の絶対値を掛けます。この J もヤコビアンと呼びます。小さな長方形が、移った先で何倍の面積になるかの補正です。

fU,V​(u,v)=fX,Y​(x,y)∣J∣

J=det(∂x/∂u∂y/∂u​∂x/∂v∂y/∂v​)

例として、X と Y が独立で、どちらも指数分布 Exp(λ) に従うときの和 U=X+Y の分布を求めます。

  1. V=X も一緒に置くと、x=v、y=u−v です
  2. J=det(01​1−1​)=−1 なので、∣J∣=1 です
  3. 同時密度は λe−λv⋅λe−λ(u−v) で、まとめると fU,V​(u,v)=λ2e−λu（0<v<u）です
  4. v について0から u まで積分すると、fU​(u)=λ2ue−λu です

これは Ga(2,λ) の密度で、指数分布とガンマ分布で学んだ「2件目が起きるまでの待ち時間」と一致します。

3. 極値分布：最大値と最小値の分布

「100年に一度の洪水の水位」「10個の部品のうち最初の1個が壊れるまでの時間」のように、たくさんの値の最大値や最小値を知りたい場面があります。

X1​,…,Xn​ が独立で、どれも分布関数 F(x)=P(X≤x) に従うとします。最大値 M が x 以下になるのは、n 個全部が x 以下のときです。最小値 m が x を超えるのは、全部が x を超えるときです。

P(M≤x)P(m>x)​=F(x)n={1−F(x)}n​

例えば0から1の一様分布から5個とると、最大値が0.8以下の確率は 0.85≈0.33 です。1個なら80%の確率で0.8以下ですが、5個の最大値は67%の確率で0.8を超えます。

最小値の例です。平均寿命1000時間の指数分布（λ=1/1000）に従う部品10個が独立に動くとき、P(m>t)=(e−λt)10=e−10λt です。最初の故障までの時間は Exp(10λ) に従い、平均は100時間です。

n を大きくしたときの形：3つの型

n を大きくすると、最大値はどんどん大きくなります。そこで、位置をずらし、幅をそろえて形だけを比べます。

平均1の指数分布なら F(x)=1−e−x です。最大値から lnn を引くと、次のようになります（(1+a/n)n→ea を使います）。

P(M−lnn≤x)​=(1−ne−x​)n→exp(−e−x)(n→∞)​

この exp(−e−x) がガンベル分布の分布関数です。e が2重になった形は、ここから来ています。

元の分布が違っても、ずらして幅をそろえた最大値に極限の分布があるなら、それは次の3つの型のどれかです（Fisher-Tippett-Gnedenko の定理）。最小値は、符号を反転すれば最大値として扱えます。

  • ガンベル型（Type I）：裾が指数的に減る分布（正規分布、指数分布など）の最大値。洪水や気温など、気象や土木の極値の分析に使います
  • フレシェ型（Type II）：裾がべき乗でゆっくり減る分布（コーシー分布、パレート分布など）の最大値。金融の大きな損失や地震の規模の分析に使います
  • ワイブル型（Type III）：上限がある分布（一様分布など）の最大値。正確には、通常のワイブル分布を左右反転した形です。通常のワイブル分布は最小値の極限として現れ、部品の寿命（一番弱い所で壊れる）に使います

3つの型は、形状パラメータ ξ をもつ一般極値分布（GEV）にまとめられます。ξ=0 がガンベル型、ξ>0 がフレシェ型、ξ<0 がワイブル型です。

Q1. 多変量正規分布において「相関係数が0」が意味することは何か？

A. 統計的独立（多変量正規分布では成立）

Q2. 身長 X（平均170cm、標準偏差6cm）と体重 Y（平均65kg、標準偏差8kg）が、相関係数0.5の2変量正規分布に従います。身長176cmの人の体重の条件付き期待値はいくらか？

A. 69 kg

Q3. 多変量正規分布 X∼Np​(μ,Σ) に対し、線形変換 Y=AX+b（A は定数行列）の分布はどれか？
