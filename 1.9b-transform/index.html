変数変換：Y = g(X) の分布とヤコビアン

X の分布から Y = g(X) の分布を求める方法を学びます。単調な変換の公式とヤコビアン、単調でない変換、2変数の変換（指数分布2つの和）。

このモジュールで学ぶこと

X の分布が分かっているとき、Y=g(X) の分布を求める方法を学びます。例えば「lnX が正規分布に従うとき、X はどんな分布か」（対数正規分布）という問いです。

  • 単調な変換の公式とヤコビアン
  • 単調でない変換（Y=X2）
  • 2つの変数をまとめて変換する

1. 確率は移しても変わらない

帯の幅と高さ

X がある区間に入る確率と、その区間を g で移した先に Y が入る確率は同じです。区間の幅が変われば、同じ面積を保つために高さ（密度）が変わります。確率分布の基礎で、X を2倍すると幅が2倍、山の高さが半分になったのと同じです。

2. 単調な変換の公式

公式とヤコビアン

g が単調増加か単調減少なら、x=g−1(y) として次の式です。

fY​(y)=fX​(x)​dydx​​,x=g−1(y)

∣dx/dy∣ は「y を少し動かしたとき、x がどれだけ動くか」で、幅の伸び縮みを補正します。これをヤコビアンと呼びます。

3. 単調でない変換：寄与を足す

2つの x が同じ y に移る

X が N(0,1) に従い Y=X2 のときは、1つの y に x=y​ と x=−y​ の2つが対応します。両方の寄与を足します。

fY​(y)​={fX​(y​)+fX​(−y​)}2y​1​=2πy​1​e−y/2,y>0​

これは自由度1のカイ二乗分布の密度で、標本分布の相互関係で使います。

4. 2つの変数をまとめて変換する

面積の倍率を掛ける

(X,Y) から (U,V) へ変換するときは、∣dx/dy∣ の代わりに、偏微分を並べた行列式 J の絶対値を掛けます。この J もヤコビアンと呼びます。小さな長方形が、移った先で何倍の面積になるかの補正です。

fU,V​(u,v)=fX,Y​(x,y)∣J∣

J=det(∂x/∂u∂y/∂u​∂x/∂v∂y/∂v​)

例：指数分布2つの和

X と Y が独立で、どちらも指数分布 Exp(λ) に従うときの和 U=X+Y の分布を求めます。

  1. V=X も一緒に置くと、x=v、y=u−v です
  2. J=det(01​1−1​)=−1 なので、∣J∣=1 です
  3. 同時密度は λe−λv⋅λe−λ(u−v)=λ2e−λu（0<v<u）です
  4. v について0から u まで積分すると、fU​(u)=λ2ue−λu です

これは Ga(2,λ) の密度で、指数分布とガンマ分布で学んだ「2件目が起きるまでの待ち時間」と一致します。手順4の積分の幅 u が、図の線分の長さにあたります。
