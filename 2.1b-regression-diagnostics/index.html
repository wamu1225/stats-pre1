回帰診断・正則化・一般化最小二乗法

VIF・てこ比・クックの距離・ダービン・ワトソン比による回帰診断、Box-Cox 変換と Ridge・Lasso 回帰、重み付き・一般化最小二乗法を学びます。

このモジュールで学ぶこと

重回帰分析では、カフェの売上を気温・週末・イベントで説明する式を最小二乗法で当てはめ、モデルの評価と変数選択で変数を選びました。ただ、当てはめた式を信頼できるのは、最小二乗法の前提（誤差の期待値が0、分散がそろう、誤差どうしが無相関）が成り立ち、係数を不安定にする変数や、1点に引っ張られた直線が無いときです。読み終えると、次の3つができるようになります。

  1. VIF・てこ比・クックの距離・ダービン・ワトソン比で、当てはめた回帰の問題点を見つけられる
  2. Box-Cox 変換や Ridge 回帰・Lasso 回帰で、仮定違反や多重共線性に対処できる
  3. 誤差のばらつきがそろわないとき、重み付き最小二乗法と一般化最小二乗法を使える

1. 回帰診断：当てはめた式の問題を見つける

当てはめた式を信じてよいかを、説明変数どうしが似すぎていないか、1つの点に直線が引っ張られていないか、誤差が時間でつながっていないかの3点で、それぞれ1つの数にして調べます。これが回帰診断です。

  • 多重共線性：説明変数どうしの相関が強いと、係数が不安定になります。VIF（Variance Inflation Factor: 分散拡大係数） が 10 を超えたら要注意。VIFj​=1/(1−Rj2​) で、Rj2​ は変数 j をほかの説明変数で回帰したときの決定係数です。たとえば気温をほかの説明変数で Rj2​=0.9 まで説明できるなら VIF は 10 で、気温の係数の分散が相関の無い場合の10倍（標準誤差は約3.2倍）に膨らみます
  • leverage（てこ比）：その点の説明変数の値が、ほかの点からどれだけ離れているか。高い点ほど回帰直線を強く引っ張ります。予測値 y^​i​ の中で yi​ 自身にかかる重み hii​（y^​=Hy と書くハット行列 H=X(X⊤X)−1X⊤ の対角成分）がてこ比で、平均 (p+1)/n（p+1 は切片を含む係数の数）の2〜3倍を超えると高いとみます
  • クックの距離：てこ比と残差がともに大きい、影響力の高い点を見つける指標。Di​=(p+1)s2ei2​​⋅(1−hii​)2hii​​（ei​ は残差、s2 は誤差分散の推定値）で、その点を除いたときに予測値がどれだけ動くかを測ります。Di​≥1（または 4/n）の点は特に要調査
  • ダービン・ワトソン比（DW比）：「残差（予測とのズレ）に時間的なつながり（系列相関）がないか」を調べる指標。DW=∑t=1n​et2​∑t=2n​(et​−et−1​)2​≈2(1−r) （r は隣どうしの残差の相関）なので、相関が無ければ 2、正の系列相関で0、負の系列相関で4に近づきます

てこ比とクックの距離の違いを、10点の例で見ます。端にある点と、中央で外れた点を比べます。

数にせず、形で見る確かめ方もあります。横軸に予測値、縦軸に残差をとった残差プロットで、点が0の上下に模様なく散らばるかを見ます。

t 検定や信頼区間の前提である残差の正規性は、正規Q-Qプロット（正規性の確認とノンパラメトリック検定）で確かめます。

誤差の分布を仮定しにくいときは、係数の標準誤差をブートストラップ法（手元のデータから復元抽出で作り直した標本で何度も推定し直す方法。シミュレーション手法：モンテカルロ法・乱数生成・ブートストラップ法で扱います）で求めることもできます。

2. 問題への対処：Box-Cox 変換と正則化回帰

Box-Cox 変換：残差の形を整える

予測値が大きいほど残差の幅が広がる（上の図の③）、残差の分布が右に長く伸びる、といった仮定違反があるとき、目的変数 y（正の値）を次の形で変換すると改善することがあります。

y(l)=⎩⎨⎧​lyl−1​logy​(l=0)(l=0)​

  • 1を引いて l で割るのは、l→0 で logy につながるようにするためです。l=1 は変換なし、l=1/2 は平方根変換に相当します。
  • l は最尤法で選びます。変換後の残差が最も正規分布に近く、等分散になる l を探す考え方です。
  • 変換したスケールで推定した係数は、元の単位に戻すと解釈が変わります。予測値は逆変換して使います。

つまずきやすい点：Box-Cox 変換は y>0 が前提です。0や負の値を含むときは、定数を足してから使います。

正則化回帰：係数を小さく抑える

VIF が大きいときや説明変数が多すぎるとき、係数が大きく揺れるのを抑えるため、残差平方和に係数の大きさの罰則を足して最小にします。これを正則化と呼びます。

Ridge 回帰（L2正則化）は、係数の2乗和を罰則にします。

β^​ridge​=argβmin​[i∑​(yi​−xi⊤​β)2+λj=1∑p​βj2​]

説明変数を標準化し、y から平均を引いておくと切片が要らなくなり、解は1つの式で書けます。

β^​ridge​=(X⊤X+λI)−1X⊤y

  • λ=0 なら通常の最小二乗法に一致し、λ を大きくするほど係数は0に向かって縮みます。
  • X⊤X の逆行列がほぼ作れない（多重共線性）ときも、λI を足すと逆行列が安定します。
  • 標準化するのは、罰則が係数の大きさに課され、単位の取り方で結果が変わるためです。切片は罰則に含めません。
  • λ は推定の偏り（バイアス）とばらつき（バリアンス）のバランスを決めます。大きいほど偏りが増え、ばらつきが減ります。通常は、データを分けて予測の誤差が最小になる λ を選びます（クロスバリデーション）。

Lasso 回帰（L1正則化）は、係数の絶対値の和を罰則にします。Ridge と違い、係数がちょうど0になる変数が出るので、変数選択も同時にできます。

β^​lasso​=argβmin​[i∑​(yi​−xi⊤​β)2+λj=1∑p​∣βj​∣]

罰則つきの最小化は「係数の大きさを一定以下に抑えた範囲（Ridge は円、Lasso はひし形）の中で残差平方和を最小にする」のと同じで、図にすると理由が見えます。

ひし形は角が軸の上にあるので、残差平方和の等高線が角で触れやすく、そのとき係数がちょうど0になります。

3. 誤差のばらつきがそろわないとき：一般化最小二乗法

重回帰分析で見たガウス＝マルコフの定理は、誤差の分散がどのデータでも同じで、誤差どうしが無相関であることを前提にしています。店の広さと売上のように、大きい店ほど売上の振れ幅も大きいと、この前提が崩れます。

最小二乗法は、どの点のズレも同じ重みで数えます。振れ幅の大きい点のズレは偶然の部分が多いのに、ほかの点と同じだけ直線を引っ張ります。そこで、残差の2乗に誤差分散の逆数 wi​=1/σi2​ の重みをかけてから和を最小にします。これが重み付き最小二乗法（WLS）です。

βmin​ i∑​wi​(yi​−xi⊤​β)2

誤差どうしに相関がある場合（時系列で前日の誤差が翌日に残るなど）も含めて、誤差の分散共分散行列を Σ と書くと、推定量は次の形になります。これが一般化最小二乗推定量（GLS）です。

β^​GLS​=(X⊤Σ−1X)−1X⊤Σ−1y

  • Σ=σ2I（分散が同じで相関なし）なら、通常の最小二乗推定量 (X⊤X)−1X⊤y に戻ります。Σ が対角行列なら重み付き最小二乗法です
  • 考え方は、データを変換して前提を満たす形に直してから最小二乗法を使う、というものです。WLS なら各行（yi​ と xi​）を σi​ で割ると、誤差の分散がそろいます
  • Σ が分かっていれば、GLS 推定量は線形不偏推定量の中で分散が最小になります（ガウス＝マルコフの定理を広げたもの）。実際には Σ を残差から推定して使います

図の下段は、同じ条件でデータを作り直したときの傾きの分布です。平均はどちらもデータを作るときに決めた傾き 0.5 で偏りはなく、違うのは精度です。傾きの標準偏差は最小二乗法で 0.0311、重み付きで 0.0207 で、分散の比は約2.3、つまり最小二乗法で同じ精度を得るには約2.3倍のデータが要ります。
