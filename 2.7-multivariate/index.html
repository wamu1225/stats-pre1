正準相関・対応分析・共分散構造分析

多次元尺度法・正準相関分析・対応分析・共分散構造分析の4手法を、扱うデータの型と答える問いで整理します。

このモジュールで学ぶこと

「理系科目の成績と文系科目の成績は、全体としてどれくらい関連しているか？」「職業と政党支持を同じ図の上に配置して関連を見たい」「学力という見えない概念を複数のテスト得点で測るモデルを作りたい」これらはPCA・判別分析・クラスター分析だけでは答えられません。このモジュールでは、そのような問いに答える多変量解析の手法群を学びます。公式の出題範囲表の多変量解析に挙がる、正準相関・対応分析・共分散構造分析（構造方程式モデル）を中心に扱います。

1. 多次元尺度法

「東京・大阪・名古屋・福岡の都市間距離から、地図上の位置関係を再現できるか？」このような問いに答えるのが多次元尺度法（MDS: Multidimensional Scaling）です。

n 個の対象間の非類似度（距離）行列を与えると、それを近似的に再現する低次元（通常2次元）空間上の座標を求めます。「距離が近いもの同士を地図上で近くに配置する」操作です。

主成分分析が「変数の次元削減」なら、MDSは「対象間の距離を保ちながら次元削減」です。実際に4都市の距離だけから位置を復元してみます。

メトリックMDS：距離を数値として使います。ノンメトリックMDS：順位情報だけを使います（「i と j は i と k より近い」という順序のみ）。

MDSは「対象間の距離」を使いましたが、次は「2つの変数グループ間の関係」を分析する手法を見ます。

2. 正準相関分析

「数学・理科の成績（変数セットX）と国語・英語の成績（変数セットY）は全体としてどれだけ関連しているか？」これを答えるのが正準相関分析（Canonical Correlation Analysis）です。

2組の変数セット X（p 変数）と Y（q 変数）に対して、正準変数の組 (Uk​,Vk​) を：

Uk​=ak⊤​X,Vk​=bk⊤​Y

Uk​ と Vk​ の相関（正準相関係数 ρk∗​）が最大になるように ak​,bk​ を選びます。

min(p,q) 組の正準対が存在し、各組は前の組と無相関になります。これはPCAの2変数版への拡張と見ることができます。

数値例：数学・理科（X1​,X2​）と国語・英語（Y1​,Y2​）の得点を標準化し、相関が次のとおりだったとします（架空の値です）。

組相関
数学と理科0.6
国語と英語0.5
数学と国語、理科と英語0.4
数学と英語、理科と国語0.3

X と Y の間の相関は、どの1組を取っても最大 0.4 です。ところが、各組の合計点どうし（U1​∝X1​+X2​、V1​∝Y1​+Y2​）を取ると、相関は ρ1∗​=(1+0.6)(1+0.5)​0.4+0.3​≈0.45 に上がります。理系の総合力と文系の総合力のあいだの関連を、個々の科目よりよく捉えているわけです。第2の組は、差の得点（U2​∝X1​−X2​、V2​∝Y1​−Y2​）で、ρ2∗​=(1−0.6)(1−0.5)​0.4−0.3​≈0.22 です。意味は「数学寄りか理科寄りか」と「国語寄りか英語寄りか」の対応で、第1の組と無相関になります。min(p,q)=2 なので、組はここまでです。

よくある誤解：「正準相関分析は重回帰分析の多変量版で、X から Y を予測する手法」と思いがちですが、誤りです。正準相関分析は X と Y について対称な手法で、「X から Y を予測する」のではなく「X と Y の間でもっとも相関が高い線形結合のペア (Uk​,Vk​) を探す」分析です。X と Y を入れ替えても同じ正準相関係数 ρk∗​ が得られます。一方、重回帰では「説明変数 → 目的変数」の方向が固定されているため、変数の役割を入れ替えると結果が変わります。

正準相関は「数値変数のグループ間の関係」を見ましたが、次は変数がカテゴリ（名義尺度）のときの視覚化手法を見ます。

3. 対応分析

「職業と政党支持の2元分割表から、どの職業がどの政党を支持しやすいかを可視化したい」これが対応分析（Correspondence Analysis）の典型的な使い方です。

行カテゴリと列カテゴリを同一の低次元空間に布置し、「近い点は関連が強い」という解釈をします。分割表データを可視化する強力な探索的手法です。

基本的には分割表の行・列プロフィールに対して特異値分解（SVD: 行列を「成分に分解する」操作で、PCAの計算にも使われる行列の基本操作）を適用します。主成分分析のカテゴリデータ版と考えられます。

数値例：240人に年代と好きな飲み物を聞いた架空のデータです。各年代80人ずつで、次の分割表になりました。

コーヒー紅茶緑茶ジュース計
20代301053580
40代2525201080
60代102045580
計65557050240

各年代の中での割合（行プロフィール）で見ると、好みの違いがはっきりします。

コーヒー紅茶緑茶ジュース
20代37.5%12.5%6.3%43.8%
40代31.3%31.3%25.0%12.5%
60代12.5%25.0%56.3%6.3%
全体27.1%22.9%29.2%20.8%

年代と飲み物が独立なら、どの年代の行も一番下の「全体」と同じ割合になるはずです。このずれを、分割表の独立性検定（3.4）と同じ計算で測ると χ2=82.4（自由度6）です。これを人数 n=240 で割った 0.343 を全慣性と呼び、人数によらず「独立からどれだけずれているか」を表します。対応分析は、この全慣性を軸ごとに振り分ける手法です。軸の数は min(3,4)−1=2 本までで、第1軸が 0.307（寄与率 89.6%）、第2軸が 0.036（10.4%）を受け持ちます。

図の読み方は次のとおりです。

  • 第1軸は左の「若い・甘い飲み物」から右の「高齢・緑茶」への並びです。20代はジュースとコーヒーの近く、60代は緑茶の近くにあります
  • 第2軸は、40代と紅茶を、両端の年代から切り離す方向です。40代は両極のどちらにも寄らず、紅茶の近くに出ます
  • 四角どうし、丸どうしの距離は、プロフィールの似かたを表します。四角と丸の距離そのものは厳密には比べられないので、「どちらの方向にあるか」で読みます

数量化法（Hayashi's Quantification Methods）は対応分析と関連する日本発の手法群で、カテゴリデータを扱う多変量解析に対応します。具体的には：

  • 数量化I類：カテゴリ変数（説明変数）をもつ重回帰分析に対応（目的変数は連続量）
  • 数量化II類：カテゴリ変数をもつ判別分析に対応
  • 数量化III類：対応分析（カテゴリデータの主成分分析）に対応
  • 数量化IV類：クラスター分析に対応

つまずきやすい点：「どの類がどの分析に対応するか」は混同しやすい対応です（I=回帰・II=判別・III=対応分析・IV=クラスター）。

対応分析が「観測変数間の関係」を可視化するのに対し、次は「直接測れない概念（潜在変数）」を含む因果構造をモデル化する手法を見ます。

4. 共分散構造分析（SEM）

「学力（潜在変数）は語彙力・読解力・計算力（観測変数）で測られる」このような「観測できない概念（潜在変数）」を含む因果関係をモデル化するのが共分散構造分析（SEM: Structural Equation Modeling）です。

SEMは2つのサブモデルからなります：

  • 測定モデル（因子分析部分）：潜在変数と観測変数の関係
  • 構造モデル（パス解析部分）：潜在変数間の因果関係

パス図（Path Diagram）：変数を四角（観測変数）や楕円（潜在変数）、矢印（因果・共分散）で表した図。

パス係数：矢印の重みで「原因変数が1標準偏差変化したとき、結果変数が何標準偏差変化するか」を表します。

モデルの適合度は χ2 検定・CFI（比較適合指標）・RMSEA（二乗平均平方根近似誤差）などで評価します。

つまずきやすい点：SEMでは「因果」は理論から来ます。矢印の向きはデータから決まるのではなく、研究者の理論的仮説を反映します。

5. 3手法の使い分け（正準相関・対応分析・SEM）

このモジュールで扱った 3 つの手法（正準相関・対応分析・SEM）は「2 つ以上の変数群の関係を捉える」という共通点がありますが、扱うデータ型と目的が異なります。

  • 正準相関分析（CCA）：2 セットの量的変数群の関連を、相関が最大になる線形結合のペアとして抽出します。例：学力テスト群（数学・国語・英語）と性格特性群（外向性・誠実性）の関係を全体として把握したい場面。
  • 対応分析：質的変数（カテゴリ）の関連を低次元プロットで可視化します。例：年代×購買カテゴリのクロス表から「20 代は化粧品、50 代は健康食品」といった対応関係を散布図で示したい場面。
  • 共分散構造分析（SEM）：潜在変数を含む構造モデル全体の適合度を検証します。例：「ストレス → 不眠 → 疲労」という因果モデルがデータに整合するかを確かめたい場面。

押さえどころ：3手法の比較表

観点CCA対応分析SEM

判断の目安：データが量的か質的かでまず CCA・SEM と対応分析を分け、量的の場合「単に関連の強さを見たい」なら CCA、「因果構造を検証したい」なら SEM と進むと迷いません。

6. 多変量解析の選択フロー

多変量解析の手法は数が多く、目的に応じた選択が重要です。「何を知りたいか」から逆算するフローで覚えると整理しやすくなります。

ステップ 1：目的を分類する

  • 関連の構造を見たい
  • 探索的に構造を探す → 因子分析・主成分分析（PCA）・正準相関分析（CCA）
  • 確認的に仮説モデルを検証 → 共分散構造分析（SEM）
  • グループ化したい
  • グループラベルがない（教師なし）→ クラスター分析
  • グループラベルがある（教師あり）→ 判別分析・ロジスティック回帰
  • カテゴリ変数の関連を見たい
  • 低次元で可視化 → 対応分析（数量化 III 類）
  • 独立性の検定 → 分割表分析（カイ二乗検定）

ステップ 2：データ型を確認する

目的変数説明変数推奨手法
量的量的重回帰・PCA・因子分析
量的質的数量化 I 類・分散分析
質的（2 値）量的ロジスティック回帰・判別分析
質的質的数量化 II 類・対応分析
なし（教師なし）量的・質的混合クラスター分析・多次元尺度法

判断の目安：「目的（要約・分類・予測・検証）」と「データ型（量的・質的）」の 2 軸を最初に決めれば、手法は自動的に絞り込めます。「○○を分析したいとき、どの手法を使うか」で迷わないよう、このフローで手法を絞り込む練習をしておくと整理できます。

確認クイズ（抜粋）

Q1. 多次元尺度法（MDS）の入力と出力を正しく説明したものはどれか？

A. 対象間の非類似度（距離）行列を入力し、低次元の座標を出力する

Q2. 正準相関分析が答える問いはどれか？

A. 2組の変数セット間の最大相関を見つける

Q3. 対応分析（Correspondence Analysis）が主に使われるデータの種類はどれか？

A. カテゴリ変数の分割表
