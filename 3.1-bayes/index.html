ベイズ推定とMCMC

「今の確信」を「新しいデータ」でアップデートし続ける、進化する統計学。

このモジュールで学ぶこと

全確率の定理とベイズの定理では、検査で陽性と出た人が病気である確率を、ベイズの定理で更新しました。ベイズ統計は、同じ更新を母数 θ（コインの表の確率など）に当てはめます。θ がどのあたりにありそうかを確率分布で表し、データを見るたびにその分布を描き直します。

読み終えると、次のことができるようになります。

  1. 事前分布と尤度から事後分布を求められる
  2. 共役事前分布で事後分布を足し算で求め、事後平均と MAP 推定を計算できる
  3. 事後分布が式で求まらないときに MCMC が何をするか、階層ベイズで推定値がどう寄るかを言える

1. ベイズの定理：事前分布を事後分布へ更新する

迷惑メールのフィルターで考えます。θ は「スパムか、正常か」の2通りです。

  • 事前分布：データを見る前の θ の分布。メールの30%がスパム
  • 尤度：その θ のもとで、見たデータが出る確率。「無料」「当選」の2語は、スパムに80%、正常メールに5%の割合で出る
  • 事後分布：データを見た後の θ の分布

2語を含むメールがスパムである確率は 0.24/0.275≈0.87 です。事前の30%から87%まで上がりました。式で書くと次のとおりです。

P(θ∣data)=∫P(data∣θ)P(θ)dθP(data∣θ)P(θ)​

分母は、図の②で残った部分をすべての θ について足した値です（θ が連続なら積分）。事後分布の合計を1にするための定数で、θ によらないので、省いて「比例する」を表す ∝ で書くことがよくあります。

P(θ∣data)∝P(data∣θ)×P(θ)

2. 共役事前分布：足し算で事後分布が求まる

∝ のままでは、平均や確率を計算できません。合計を1にする分母の積分が要ります。事前分布をうまく選ぶと、この積分を解かずに済みます。コインを10回投げて7回表が出たとします。表の確率 p の事前分布にベータ分布 Beta(α,β) を置くと、尤度との積は指数が足されるだけです（係数は p によらないので省きます）。

​pα−1(1−p)β−1×p7(1−p)3=pα+7−1(1−p)β+3−1​

事後分布もベータ分布 Beta(α+7, β+3) の形になります。ベータ分布は合計を1にする係数が分かっているので、分母の積分は要りません。このように事後分布が事前分布と同じ種類になる事前分布を共役事前分布と呼びます。代表的な組み合わせは次の3つです。

  • 二項分布の p（n 回中 k 回成功）：Beta(α,β) → Beta(α+k, β+n−k)
  • ポアソン分布の λ：Ga(α,β) → Ga(α+∑xi​, β+n)（β は率のパラメータ）
  • 正規分布の平均 μ（データの分散 σ2 は既知）：N(μ0​,τ2) → 正規分布。分散の逆数が足し算になり、事後分布の分散の逆数は 1/τ2+n/σ2。事後平均は、μ0​ とデータの平均をこの2つの比で混ぜた値

事後分布から値を1つ選ぶ方法は2つあります。事後平均（EAP）は事後分布の平均、MAP 推定は事後分布の最頻値（山の頂上）です。Beta(a,b) の平均は a+ba​、最頻値は a+b−2a−1​ です。

一様な Beta(1,1) から始めると、事後分布は Beta(8,4) で、事後平均 8/12≈0.67、MAP 推定 7/10=0.70 です。事前分布が平らなので、MAP 推定は最尤推定と一致します。「コインは偏っていないはずだ」を Beta(5,5) で表すと、事後分布は Beta(12,8) で、事後平均 0.60、MAP 推定 11/18≈0.61 です。

データが100回中70回に増えると、Beta(5,5) から始めても Beta(75,35) で事後平均は約 0.68 になり、事前分布の影響は小さくなります。下の操作図は正規分布の平均 μ の場合で、事前分布 N(0,1)（点線）に、平均 1.5・標準偏差 0.5 のデータを n 個加えた事後分布を塗りで描いています。

n を増やすと、事後分布は 1.5 のまわりで細く高くなり、事前分布の中心 0 から離れていきます。

3. 無情報事前分布とジェフリーズ事前分布

事前知識が無いとき、「どの値も同じくらいもっともらしい」として一様分布を事前分布に使う考え方を無情報事前分布と呼びます。事後分布の形は尤度と同じになり、MAP 推定は最尤推定と一致します（前節の Beta(1,1) の例）。

ただし一様分布は変数変換に対して不変でないという問題があります。p に一様分布を置いても、log(p/(1−p)) は一様分布になりません。どの尺度で「平ら」にするかで答えが変わります。ジェフリーズ事前分布は、フィッシャー情報量 I(θ) を使って π(θ)∝I(θ)​ と定め、どの尺度で書いても同じ事前分布になります。二項分布の p なら I(p)∝1/{p(1−p)} なので、その平方根 p−1/2(1−p)−1/2、つまり Beta(1/2, 1/2) です。

4. MCMC：事後分布からサンプルを作る

共役でない組み合わせでは、分母の積分が式で解けません。母数が10個、100個あれば、10次元・100次元の空間での積分です。そこで使うのが MCMC（マルコフ連鎖モンテカルロ法）です。事後分布の式を求める代わりに、事後分布に従う値（サンプル）を大量に作り、そのヒストグラムで形をつかみます。多くの方法は、いまの値と候補の値を比べ、事後確率が高い方へ移りやすくします。2つの比をとるので、分母は打ち消し合って要りません。

  • マルコフ連鎖：次の値を1つ前の値だけから確率的に決める列。長く続けると値の分布が一定の分布に落ち着くので、その落ち着き先が事後分布になるような連鎖を使います。連鎖の性質は次のマルコフ連鎖と確率過程の基礎で学びます
  • ギブスサンプリング：母数が複数あるとき、他を固定して1つずつ、その条件付き分布から順番に値を引く方法
  • 周辺化：母数が θ1​,θ2​ の2つあり、θ1​ だけを知りたいときは、θ2​ について積分して消した分布 P(θ1​∣data)=∫P(θ1​,θ2​∣data)dθ2​ を見ます。MCMC のサンプルなら、θ1​ の値だけを取り出してヒストグラムにすれば済みます

5. 階層ベイズモデル

複数のグループ（たとえば複数の学校の平均点）を分析するとき、各グループの母数 θj​ を別々に推定すると、データの少ないグループは推定が不安定になります。階層ベイズモデルでは、各 θj​ に共通の事前分布 θj​∼N(μ,τ2) を置き、その μ や τ2 にもさらに事前分布（超事前分布）を置きます。

事前分布の中の母数もデータから学ぶ、という二段構えが「階層」という名前の由来です。グループどうしの似かたもデータから推定され、データの少ないグループの推定値は全体の平均へ引き寄せられます（縮小）。

事後分布は複雑になるため、計算には MCMC を使うのが一般的です。

確認クイズ（抜粋）

Q1. ベイズ推定において、データを得る前に設定する母数の確率分布を何と呼ぶ？

A. 事前分布

Q2. 表の確率 p の事前分布を Beta(2,2) とし、コインを10回投げて6回表が出た。事後平均はいくらか？

A. 0.57

Q3. 事前分布と事後分布が同じ種類の分布（関数形）になるような、計算上便利な事前分布は？

A. 共役事前分布
