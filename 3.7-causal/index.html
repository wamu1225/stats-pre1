統計的因果推論：DAG とバックドア基準

潜在結果と平均処置効果、因果グラフ（DAG）と有向分離、バックドア基準と調整公式を、シンプソンのパラドックスの数値例で学びます。

このモジュールで学ぶこと

「アイスの売上と水難事故は同時に増える。アイスを禁止すれば事故は減るのか？」相関から因果を読むには、データだけでなくどんな原因の構造を仮定するかが要ります。読み終えると、次の3つができるようになります。

  1. 潜在結果と平均処置効果の考え方で、観察データの単純な差が因果効果にならない理由を言える
  2. 因果グラフ（DAG）で、交絡・媒介・合流点の経路が条件づけで開くか閉じるかを判定できる
  3. バックドア基準を満たす変数を選び、調整公式で因果効果を計算できる

交絡を測れないときの方法（フロントドア基準・操作変数）と、効果を直接効果と間接効果に分ける考え方は、フロントドア基準・直接効果と間接効果・操作変数で扱います。

1. 因果効果とは：観測できない「もしも」との差

薬 X（飲む＝1、飲まない＝0）の効果を考えます。同じ人について、飲んだ場合の結果 Y(1) と飲まなかった場合の結果 Y(0) を潜在結果と呼びます。その人にとっての効果は Y(1)−Y(0) ですが、実際に起きるのはどちらか一方だけで、もう一方は永久に観測できません。4人で書くと、表の「？」は永久に埋まりません。これが因果推論の根本問題です。

人飲んだか XY(1) 飲んだら回復Y(0) 飲まなければ回復
111？
210？
30？1
40？0

そこで集団で平均をとった平均処置効果（ATE）を目標にします。

ATE=E[Y(1)−Y(0)]

観測できるのは E[Y∣X=1] と E[Y∣X=0] の差ですが、これが ATE に一致する保証はありません。薬を飲む人と飲まない人では、もともとの状態が違うかもしれないからです。

無作為割り付けをすると、飲む人と飲まない人が（平均的に）同じ集団になるので、単純な差がそのまま ATE になります。観察データでは割り付けを選べないので、どの変数で分けて比べれば同じことができるかを、次の2つの節で決めます。

2. 因果グラフ（DAG）：矢印で原因の構造を描く

どの変数で分けて比べればよいかは、データの数字だけでは決まらず、原因の構造を図に描いて決めます。

変数を点、「原因→結果」を矢印で結び、矢印をたどって元の変数に戻る輪（循環）が無いグラフをDAG（有向非巡回グラフ）と呼びます。2変数のあいだの経路は、途中の矢印の向きで3つの基本形に分かれます。冒頭のアイスと水難事故は、気温が共通原因の①です。

形経路何もしないとき途中の変数で条件づけると
交絡（分岐）X←Z→Y経路は開いている（見かけの関連）経路が閉じる（Z ごとに比べる）
媒介（連鎖）X→M→Y経路は開いている（本物の効果）経路が閉じる（効果の通り道を塞ぐ）
合流点X→C←Y経路は閉じている経路が開く（見かけの関連が生まれる）

表の「条件づける」は、途中の変数の値ごとに分けて見ることです。合流点だけ、条件づけの効果が逆なのが落とし穴です。「俳優は演技力と容姿の少なくとも一方が優れている」とすると、C＝俳優になれたか、です。一般の人では演技力と容姿に関係がなくても、俳優だけを集めると「演技力が低い人ほど容姿が良い」という負の関連が現れます。C やその子孫（C から矢印をたどって行き着く変数）で絞り込むと、こうした見かけの関連が作られます。

有向分離（d-分離）は、この開閉のルールを経路全体に当てはめたものです。変数の集合 S で条件づけたとき、X と Y を結ぶすべての経路が閉じていれば、X と Y は S で有向分離されるといい、グラフが正しければ、S を与えたとき X と Y は条件付き独立になります。次のどちらかが成り立てば、その経路は閉じます。

  • 経路上に連鎖か分岐の中間変数があり、それが S に入っている
  • 経路上に合流点があり、その合流点もその子孫も S に入っていない

練習：A→B→C←D で、A と D を結ぶ経路は1本だけで、C が合流点です。条件 S を4通りに変えると、次のようになります。

3. バックドア基準：交絡を調整で消す

薬 X を飲んだか、重症度 Z、回復 Y の1000人のデータで、薬が効くかを考えます。重症の人ほど薬を飲みやすい状況です。

治療群 回復／人数非治療群 回復／人数
軽症（500人）90 ／ 100（0.90）340 ／ 400（0.85）
重症（500人）240 ／ 400（0.60）50 ／ 100（0.50）
全体330 ／ 500（0.66）390 ／ 500（0.78）

全体では治療群が 0.66、非治療群が 0.78 で、薬を飲んだほうが 0.12 悪いように見えます。ところが軽症・重症のどちらの層でも、治療群のほうが良い。治療群500人のうち400人が、もともと回復しにくい重症者だからです。

図の DAG で、X と Y を結ぶ経路は2本です。X→Y が薬の効果、X←Z→Y のように X に入る矢印から始まる経路をバックドア経路と呼びます。全体の差には、この経路を通る因果でない関連が混ざっています。

変数の集合 Z が次の2つを満たすとき、バックドア基準を満たすといいます。

  1. Z に X の子孫が含まれない
  2. Z が、X に入る矢印で始まるすべての経路を閉じている

このとき、Z の層ごとの回復率を層の割合 P(z) で重みづけて平均する調整公式で、因果効果が求まります。

P(y∣do(x))=z∑​P(y∣x,z)P(z)

do(x) は「X を外から x に固定する」介入を表し、P(y∣x)（見ているだけ）とは区別します。条件1が要るのは、X の結果である変数を調整すると、効果の一部（媒介）を消したり、合流点を開いたりするからです。

例では重症度 Z が基準を満たし、P(Z=軽症)=P(Z=重症)=0.5 なので：

治療: 非治療: ​0.5×0.90+0.5×0.60=0.750.5×0.85+0.5×0.50=0.675​

差は +0.075 で、層ごとの向きと一致します。全体の差と調整後の差で符号が逆転する現象がシンプソンのパラドックスで、どちらを採るかはデータでなく因果グラフで決まります。Z が薬を飲んだ後に決まる変数なら、条件1により調整しません。

無作為割り付けでは X が乱数だけで決まるので、Z→X の矢印が無くなり、バックドア経路そのものが消えます。調整しなくても単純な差がそのまま ATE になるのは、このためです。

確認クイズ（抜粋）

Q1. 潜在結果の考え方で、個人の因果効果 Y(1)−Y(0) を直接求められない理由はどれか？

A. 同じ人について、実際に観測できるのは Y(1) か Y(0) の一方だけだから

Q2. 重症度 Z（軽症・重症が各50%）で層別した結果、治療群の回復率が軽症で 0.90・重症で 0.60、非治療群が軽症で 0.85・重症で 0.50 だった。調整公式による治療の平均効果（回復率の差）はいくらか？

A. +0.075

Q3. X←Z→Y という交絡の経路を閉じるには、どうすればよいか？

A. Z で条件づける（層別・調整する）
