統計的因果推論

因果グラフ（DAG）・バックドア基準・フロントドア基準・直接効果と間接効果で、相関から因果へ進む考え方を学びます。

このモジュールで学ぶこと

「アイスの売上と水難事故は同時に増える。アイスを禁止すれば事故は減るのか？」相関から因果を読むには、データだけでなくどんな原因の構造を仮定するかが要ります。このモジュールでは、因果の構造を矢印で描く因果グラフ（DAG）と、その上で「どの変数を調整すれば因果効果が求まるか」を決める道具（バックドア基準・フロントドア基準）、そして効果を直接効果と間接効果に分ける考え方を学びます。

1. 因果効果とは：観測できない「もしも」との差

薬 X（飲む＝1、飲まない＝0）の効果を考えます。同じ人について、飲んだ場合の結果 Y(1) と飲まなかった場合の結果 Y(0) を潜在結果と呼びます。その人にとっての効果は Y(1)−Y(0) ですが、実際に起きるのはどちらか一方だけで、もう一方は永久に観測できません。これが因果推論の根本問題です。

そこで集団で平均をとった平均処置効果（ATE）を目標にします。

ATE=E[Y(1)−Y(0)]

観測できるのは E[Y∣X=1] と E[Y∣X=0] の差ですが、これが ATE に一致する保証はありません。薬を飲む人と飲まない人では、もともとの状態が違うかもしれないからです。無作為割り付けをすると、飲む人と飲まない人が（平均的に）同じ集団になるので、単純な差がそのまま ATE になります。観察データではこの役目を、次に述べる調整が担います。

2. 因果グラフ（DAG）：矢印で原因の構造を描く

変数を点、「原因→結果」を矢印で結び、矢印をたどって元の変数に戻る輪（循環）が無いグラフをDAG（有向非巡回グラフ）と呼びます。2変数のあいだの経路は、途中の矢印の向きで3つの基本形に分かれます。

形経路何もしないとき途中の変数で条件づけると
交絡（分岐）X←Z→Y経路は開いている（見かけの関連）経路が閉じる（Z ごとに比べる）
媒介（連鎖）X→M→Y経路は開いている（本物の効果）経路が閉じる（効果の通り道を塞ぐ）
合流点X→C←Y経路は閉じている経路が開く（見かけの関連が生まれる）

合流点だけ、条件づけの効果が逆なのが落とし穴です。「俳優は演技力と容姿の少なくとも一方が優れている」とすると、C＝俳優になれたか、です。一般の人では演技力と容姿に関係がなくても、俳優だけを集めると「演技力が低い人ほど容姿が良い」という負の関連が現れます。C やその子孫で絞り込むと、こうした見かけの関連が作られます。

有向分離（d-分離）は、この開閉のルールを経路全体に当てはめたものです。変数の集合 S で条件づけたとき、X と Y を結ぶすべての経路が閉じていれば、X と Y は S で有向分離されるといい、グラフが正しければ、S を与えたとき X と Y は条件付き独立になります。経路が閉じる条件は次の2つです。

  • 経路上に連鎖か分岐の中間変数があり、それが S に入っている
  • 経路上に合流点があり、その合流点もその子孫も S に入っていない

練習：A→B→C←D という4変数の鎖で、A と D を結ぶ経路は1本だけで、C が合流点です。

  • 何も条件づけない（S=∅）：合流点 C が閉じているので、A と D は有向分離され、独立です
  • S={B}：合流点 C はまだ条件に入っていないので、経路は閉じたままです。A と D は独立のままです
  • S={C}：合流点を条件に入れたので経路が開き、A と D は独立でなくなります
  • S={B,C}：C が条件に入って合流点は開きますが、連鎖の中間変数 B も条件に入っているので、そこで経路が閉じます。A と D は条件付き独立です

つまり、経路が閉じるには、連鎖・分岐の中間変数が1つでも条件に入っていれば足ります（合流点が開いても、別の場所で閉じていれば経路全体は閉じる）。

3. バックドア基準：交絡を調整で消す

X から Y への因果効果を求めたいとします。X に入る矢印から始まる経路（X←⋯Y）をバックドア経路と呼びます。交絡の正体はこの経路で、X と Y の関連に、因果でない分が混ざる原因になります。

変数の集合 Z が次の2つを満たすとき、バックドア基準を満たすといいます。

  1. Z に X の子孫（X から矢印をたどって行き着く変数）が含まれない
  2. Z が、X に入る矢印で始まるすべての経路を閉じている

このとき、Z で層別して平均をとる調整公式で因果効果が求まります。

P(y∣do(x))=z∑​P(y∣x,z)P(z)

do(x) は「X を外から x に固定する」介入を表し、P(y∣x)（見ているだけ）とは区別します。条件1が要るのは、X の結果である変数を調整すると、効果の一部（媒介）を消したり、合流点を開いたりするからです。

数値例：薬 X を飲んだか、重症度 Z（重症の人ほど薬を飲みやすい）、回復 Y。1000人のデータ：

治療群 回復／人数非治療群 回復／人数
軽症（500人）90 ／ 100（0.90）340 ／ 400（0.85）
重症（500人）240 ／ 400（0.60）50 ／ 100（0.50）
全体330 ／ 500（0.66）390 ／ 500（0.78）

全体で比べると、治療群の回復率は 0.66、非治療群は 0.78 で、薬を飲んだほうが 0.12 悪いように見えます。ところが、重症の人は治療を受けやすく、もともと回復しにくいので、治療群に重症者が集中しています（重症度 Z が交絡）。Z で調整すると、P(Z=軽症)=P(Z=重症)=0.5 なので：

治療: 非治療: ​0.5×0.90+0.5×0.60=0.750.5×0.85+0.5×0.50=0.675​

差は 0.75−0.675=+0.075 で、層ごとに見た向き（どちらの層でも治療群のほうが良い）と一致します。全体の差と調整後の差で符号が逆転する現象がシンプソンのパラドックスで、どちらを採るかはデータでなく、因果グラフ（この例では Z→X と Z→Y）で決まります。

4. フロントドア基準：交絡を測れないとき

交絡 U が観測できないと、バックドア基準は使えません。それでも、X から Y への影響がすべて媒介変数 M を通ると仮定でき、M が観測できるなら、別の道があります。

次の3条件を満たす M を使うのがフロントドア基準です。

  1. X から Y へのすべての有向経路が M を通る
  2. X から M へのバックドア経路がない
  3. M から Y へのバックドア経路は、すべて X で閉じられる

このとき、効果を2段階に分けて求めます。g(m) は「M=m のときの Y への効果」を X で調整して求めた値です。

P(y∣do(x))g(m)​=m∑​P(m∣x)g(m)=x′∑​P(y∣m,x′)P(x′)​

1段目 P(m∣x) は「X が M をどう変えるか」で、U の影響を受けません（X→M に交絡がないため）。2段目は「M が Y をどう変えるか」を、X で調整して求めます（M←X←U→Y という裏道を X で閉じる）。この2つを掛け合わせて足し上げるわけです。

5. 直接効果と間接効果

X が Y に与える効果には、M を経由しない直接効果と、M を経由する間接効果があります。

線形で、交互作用がなく、未観測の交絡もない場合に限って、係数で足し算ができます。X→M の係数を a、M→Y を b、X→Y の直接の係数を c とおくと：

総合効果=c+ab,直接効果=c,間接効果=ab

たとえば a=0.5, b=0.8, c=0.3 なら、間接効果は 0.5×0.8=0.4、総合効果は 0.3+0.4=0.7 です。

M を調整するかどうかで、求まる効果が変わる点に注意が要ります。X の総合効果を知りたいときは M を調整してはいけません（間接の通り道を塞ぐため）。M を回帰モデルに入れると求まるのは直接効果です。一般の（非線形な）モデルでは、直接効果・間接効果をそれぞれ「M を固定した効果」「M だけを変えた効果」として潜在結果で定義し直す必要があります。

押さえどころ：まず「調整してよいのは交絡（分岐）の中間変数。媒介は塞ぎ、合流点は開くので調整してはいけない」という開閉の区別が大前提です。そのうえで、バックドア基準は「交絡を測れるときの調整公式 ∑z​P(y∣x,z)P(z)」、フロントドア基準は「交絡を測れないが媒介 M が測れるときの2段階の式」と使い分けます。

確認クイズ（抜粋）

Q1. 潜在結果の考え方で、個人の因果効果 Y(1)−Y(0) を直接求められない理由はどれか？

A. 同じ人について、実際に観測できるのは Y(1) か Y(0) の一方だけだから

Q2. 重症度 Z（軽症・重症が各50%）で層別した結果、治療群の回復率が軽症で 0.90・重症で 0.60、非治療群が軽症で 0.85・重症で 0.50 だった。調整公式による治療の平均効果（回復率の差）はいくらか？

A. +0.075

Q3. X←Z→Y という交絡の経路を閉じるには、どうすればよいか？

A. Z で条件づける（層別・調整する）
