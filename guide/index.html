試験ガイド

統計検定準1級の試験概要・学習戦略・推奨リソースをまとめています。

試験の概要

実施方式CBT（Computer Based Testing）— 通年受験可
出題形式5肢選択 ＋ 数値入力
問題数 / 試験時間25〜30問 / 90分（1問あたり約3分）
合格基準100点満点中 60点以上
受験料一般 8,000円 / 学割 6,000円（税込）
電卓持ち込み可（四則演算・ルート・メモリのみ）
再受験前回受験終了から7日以上経過後に可

90分で30問近くの高度な計算・解釈問題を解くには解法の自動化が鍵。理論を理解するだけでなく、典型問題を反射的に解けるまで繰り返す。

※ 受験料・試験形式は変更される場合があります。最新情報は統計検定公式サイトでご確認ください。

必要な学習時間の目安

統計の学習経験なし（統計学が初めて）：400〜500時間（6ヶ月〜1年）

統計の基礎知識あり（統計検定2級合格済み）：200〜300時間（4〜6ヶ月）

※ 短期合格者の記録に惑わされず、着実に積み上げることが重要。未経験者は数式の背景まで掘り下げると想定以上に時間がかかる傾向がある。線形代数・微積分の素養がある方は2級ルートでもさらに短縮できる場合がある。

3段階の学習フェーズ

フェーズ1｜インプット・概観フェーズ：『統計学実践ワークブック』を一通り読み、試験範囲の全体像を把握する。細かな数式に固執せず、まず「どんな手法があり、どう関連しているか」のマップを頭に入れる。

フェーズ2｜理論深化・ノート作成フェーズ：各章を精読し、数式の導出を自力で行う。合格者の多くが「自作ノート」を作成している。線形代数・微積分の基礎を固めると多変量解析の理解が加速する。

フェーズ3｜アウトプット・定着フェーズ：章末問題を解法が自動化されるまで繰り返す（目安5〜6周）。その後、公式過去問集で本番の問い方・時間配分に慣れる。

推奨書籍

  • 統計学実践ワークブック（必須・★★★★★）：試験範囲をほぼ網羅。CBT出題のベース。章末問題の習得が合格の絶対条件。
  • 統計検定準1級 公式問題集（必須・★★★★★）：過去の出題パターン確認に不可欠。解説が簡素なためワークブックと併用する。
  • 統計学入門（東京大学出版会）（推奨・★★★★☆）：通称「赤本」。基礎理論を深く理解するための補完書。
  • はじめての多変量解析（推奨・★★★★☆）：主成分分析・因子分析など難解な多変量手法を平易に解説。
  • 道具としてのベイズ統計（参考・★★★☆☆）：ベイズ統計の入門書。準1級の出題比重に合わせた概念理解に。

おすすめ無料リソース

  • とけたろうチャンネル（YouTube / note）：準1級の全範囲を網羅した解説動画とチートシート。受験生から「最強の武器」と評される。
  • あつまれ統計の森 / DataArts（ブログ）：ワークブックの解答例が不十分な箇所の詳細な導出と補足。答え合わせの補助として有用。
  • Yuya Kawaguchi（YouTube）：数学的な導出をホワイトボードで丁寧に解説。文系出身・数式に不安がある人向け。
  • 生成AI（ChatGPT / Perplexity）：ワークブックの難解な数式をステップバイステップで解説させる。証明の行間を埋める24時間家庭教師として活用できる。

重要出題分野

  • 多変量解析（最重要）：主成分分析・因子分析・判別分析・クラスター分析。準1級の合否を最も左右するエリア。
  • 統計ソフト出力の解釈（最重要）：R/Pythonの回帰分析・分散分析表の出力からp値・VIF・F値を読み取る問題が増加中。
  • ベイズ統計（重要）：共役事前分布・事後分布の更新・MCMCの基本的な考え方。
  • 時系列解析（重要）：AR・MAモデル・自己相関・定常性の概念。ARIMA・スペクトル解析。
  • モデル選択・評価（重要）：AIC・BIC・ROC曲線・AUC。計算だけでなく意味を深く問われる。
  • 分散分析（ANOVA）（標準）：自由度・平均平方・F値の関係性。分散分析表の空欄補充。

本番に向けた実践アドバイス

  • 時間感覚を身につける：1問あたり平均3分が目安。解けない問題に時間をかけすぎず、確実に取れる問題から先に解く。
  • 電卓操作に習熟する：ルート計算・メモリ機能を含む操作に慣れておく。CBTでは計算ミスが直接失点につながる。
  • 優先度をつけて学習する：多変量解析と統計ソフト出力解釈を最優先に。ただしCBTは問題のランダム性が高いため、極端な捨て科目はリスクを伴う。
  • 数学的基礎を固める：行列の積・逆行列・固有値分解の理解が多変量解析の理解を劇的に加速させる。

このサイトの学習リファレンスは、試験範囲に沿って構成されています。各モジュールの理解度チェックで定着を確認しながら進めましょう。
